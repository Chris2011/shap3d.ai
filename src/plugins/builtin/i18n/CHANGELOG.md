# Changelog – Languages

## [Unreleased]

Nothing yet.

## [1.0.2] – 2026-10-22 · Shap3D.ai (unreleased)

### Fixed

- The template for new languages (`template.json` and the editor's *Template* button) only holds the texts of the core and of this plugin – other plugins, built-in or not, bring their own language files.

## [1.0.1] – 2026-10-22 · Shap3D.ai 0.7.0

### Added

- Translations for the new switches of the ground grid (axes, labels) in German, French, Spanish and Arabic.

## [1.0.0] – 2026-10-20 · Shap3D.ai 0.6.0

### Added

- German, French, Spanish and Arabic (right-to-left) for the app; English is built in and the fallback.
- The language switch in the top bar and a *Language: …* command per language.
- The translation editor: areas, search, progress, live preview and *where is this text?*, import and export of language files (JSON) and a template for new languages.
